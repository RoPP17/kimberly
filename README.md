# Para Kimberly — *Donde el silencio tiene sentido*

Una experiencia interactiva construida con Three.js, shaders GLSL personalizados, post-procesado óptico (`UnrealBloomPass`), síntesis polifónica generativa de piano de fieltro y cuerdas en Web Audio API, paralaje 3D por mapa de profundidad y simulación gravitacional de dos cuerpos.

En vivo en: **[https://ropp17.github.io/kimberly/](https://ropp17.github.io/kimberly/)**
